Avant de commencer

  • Un compte Google est nécessaire pour exécuter les notebooks. Sans compte, mettez-vous en binôme.
  • Un notebook s'ouvre en lecture seule. Faites Fichier → Enregistrer une copie dans Drive pour travailler sur la vôtre : l'original reste intact.
  • Notebook 1 : la séquence d'ADN est incluse dans le notebook. Il n'y a rien à télécharger et aucune bibliothèque à installer.
  • Notebook 2 : la première cellule installe py3Dmol, pour l'affichage 3D, et les structures sont téléchargées depuis la Protein Data Bank et AlphaFold DB, avec une copie de secours dans ce dépôt. Sans compte sur le serveur AlphaFold, le notebook utilise des prédictions de secours.
  • Notebook 3 : le tableau des pays est inclus dans le notebook. Il n'y a rien à télécharger ni à installer ; les graphiques utilisent matplotlib, présent dans Colab.
